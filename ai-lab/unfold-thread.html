Side project · Working with Claude

From one idea to a live browser extension, in conversation

Some email threads run for years, and Gmail makes them hard to follow. I built Unfold Thread with Claude as my build partner: a private extension that turns any Gmail thread into one dated conversation, with every attachment in one place. This page shows how it went from a single prompt to a live listing on the Chrome Web Store, with the brand, website, store assets and promo film along the way.

Live on Chrome and Edge Stores and sends nothing Chrome, Edge, Brave, Arc, Opera unfoldthread.run
Unfold Thread session
01 The idea
PG
Pinky

I want to build an extension for Chrome and other browsers that shows an email thread as a conversation. If a thread started on 25 May and is still going, one button should show every email in date order, with the attachments that came with them. It has to be very secure: nothing stored, it just rolls up the emails for you.

C
Claude

Here's a first working version on Manifest V3, built around privacy:

  • It reads only the thread already on screen. No Gmail API and no sign-in.
  • No network requests, no browser storage, no analytics.
  • The conversation opens in a sealed overlay, isolated from the rest of Gmail.
  • Email content is rebuilt through an allowlist sanitizer, and remote tracking images are dropped.
02 Who it's for
PG
Pinky

Do any extensions like this already exist? I want to market it to lawyers and similar professionals who deal with threads that run for years.

C
Claude

Gmail's threading, inbox add-ons and email-to-PDF tools exist, but none of them offers a private, dated conversation with attachments in line.

For lawyers, consultants and agencies, a thread is a record. Confidential client email can't go through a third-party server, so privacy becomes the main message, not a footnote.

03 The first bug
PG
Pinky

The extension isn't working. Nothing happens when I click it.

C
Claude

It wasn't loaded into Gmail tabs that were open before you installed it. It now starts on demand when you click the toolbar icon.

PG
Pinky

This works fine.

04 Proof, filters and search
PG
Pinky

How do I know none of the data is being read or stored? Also, can we add a filter for people, and search?

C
Claude

I wrote an audit script that scans the code for network calls, storage, cookies and unsafe code. It comes back clean, and anyone can run it.

Each participant now has a chip with their message count, so you can cut the thread down to one person.

PG
Pinky

Can search work like it does in WhatsApp?

C
Claude

Yes. Matches light up in place, it starts at the newest one, and the arrows (or Enter and Shift+Enter) step through them with a "3 of 7" count.

07 A site that's found
PG
Pinky

Let's build a one-page site with a privacy page and a fictional thread, and a "Who it's for" section for lawyers, design firms and consulting agencies. Check search volume for keywords and optimize for them.

C
Claude

The stores need a privacy policy and a support page anyway, so the site does double duty.

  • Google Trends checks shaped the title, headings and FAQ around how people actually search.
  • Every screen uses a fictional case, Brindlewood Homes v Calder & Finch: ten messages over two and a half years, so no real client email ever appears.

Key takeaways

What I learned shipping it

Unfold Thread is the first product I took from idea to a public store listing on my own: the extension, the brand, the website, the store assets and the review process.

Privacy as the product

For lawyers, a tool that reads client email has to prove it keeps nothing. No network calls, no storage, and an audit script anyone can run.

A fictional case for every screen

One invented legal thread powers the screenshots, the site, the store listing and the film, so real email never appears anywhere.

Built from familiar patterns

Search works like WhatsApp and people show as chips, so a thread spanning years feels like a chat anyone already knows how to read.

Review is part of the design

Store feedback on support, contact and keywords was fixed one item at a time, and each fix made the listing clearer.
